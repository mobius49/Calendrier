CALENDRIER — PWA

Contenu :
- index.html, styles.css, app.js : application
- manifest.webmanifest : configuration d'installation PWA
- sw.js : fonctionnement hors connexion
- icons/ : icônes de l'application

Publication sur GitHub Pages :
1. Décompressez l'archive.
2. Importez tous les fichiers et le dossier icons à la racine d'un dépôt GitHub public.
3. Dans Settings > Pages, choisissez Deploy from a branch, puis la branche main et le dossier /(root).
4. Enregistrez et attendez la publication.
5. Ouvrez l'adresse GitHub Pages sur Android puis utilisez le menu du navigateur > Installer l'application / Ajouter à l'écran d'accueil.

Les données sont enregistrées localement dans le navigateur de l'appareil. Utilisez « Sauvegarder » pour exporter un fichier JSON et « Ouvrir une sauvegarde » pour le restaurer sur un autre appareil.
